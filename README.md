# 🧠 Knowledge Quiz

### 🎯 Test Your Knowledge. Challenge Yourself. Learn Something New!

**Knowledge Quiz** is an interactive and engaging quiz application designed to test users' general knowledge through a collection of multiple-choice questions.

The project provides a simple and user-friendly interface where users can answer questions, navigate through the quiz, and evaluate their knowledge based on their performance.

This project was developed as part of my **DecodeLabs Internship**, giving me practical experience in building an interactive web application and connecting frontend functionality with a Python backend.

---

## ✨ Key Features

* 🧠 Interactive knowledge-based questions
* 🎯 Multiple-choice quiz format
* 📊 Score calculation
* ⚡ Instant user interaction
* 🎨 Clean and attractive user interface
* 📱 Responsive design
* 🔄 Easy quiz navigation
* 🏆 Helps users test and improve their knowledge

---

## 🛠️ Technologies Used

* **Python** – Backend development
* **HTML5** – Webpage structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactive functionality
* **Flask** – Python web framework

## ⚙️ How the Quiz Works

1. 🚀 Launch the Knowledge Quiz application.
2. 🧠 Read each question carefully.
3. ✅ Select your preferred answer.
4. ➡️ Continue through the available questions.
5. 📊 Complete the quiz to calculate your score.
6. 🏆 Check your final performance.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/pallavipallavidn60-glitch/DecodeLabs-Internship-04.git
```

### 2. Open the Project

```bash
cd DecodeLabs-Internship-04
```

### 3. Install Required Packages

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install Flask:

```bash
pip install flask
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Browser

After running the application, open the local URL shown in your terminal, commonly:

```text
http://127.0.0.1:5000/
```
